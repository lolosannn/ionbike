# Seguridad

## Cómo reportar una vulnerabilidad

Si encontrás una falla de seguridad en la tienda, escribinos a **ionbikestore@gmail.com** con el asunto
"Seguridad" y los pasos para reproducirla. Por favor no la publiques ni la uses hasta que la corrijamos:
te respondemos dentro de las 72 horas.

Pruebas permitidas: solo contra el entorno de pruebas que acordemos. No ataques Mercado Pago, Andreani,
GitHub ni otros servicios de terceros, no hagas pruebas de denegación de servicio y no accedas a datos de
clientes reales.

Las medidas implementadas y los puntos pendientes están en [`docs/seguridad.md`](docs/seguridad.md).
